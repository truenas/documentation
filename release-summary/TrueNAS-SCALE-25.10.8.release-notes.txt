## TrueNAS 25.10.8

This maintenance release updates the Linux kernel to address more than 1,600 upstream CVEs and fixes a dataset passphrase exposure in internal job arguments, NVMe over TCP I/O errors on large transfers, and SMB, rsync, Cloud Sync, TrueNAS Connect, and Apps issues.

- **Security:** Updates the Linux kernel to v6.12.113, which includes fixes for more than 1,600 upstream CVEs. Critical fixes in components TrueNAS uses include NFS server use-after-free errors (CVE-2026-89662, CVE-2026-89658, CVE-2026-89659, CVE-2026-89660, CVE-2026-90036, CVE-2026-90037, CVE-2026-89708), a use-after-free in the NFS lock manager (CVE-2026-89485), memory errors in Kerberos-protected NFS message processing (CVE-2026-89551, CVE-2026-89542), missing length checks and a heap overflow in NVMe over TCP (CVE-2026-89482, CVE-2026-98725), and network stack issues in IP fragment queues, BIG TCP aggregation, and IPv4 checksum offsets from guests (CVE-2026-74662, CVE-2026-80725, CVE-2026-99999). Also stops dataset passphrases from appearing in plain text in the arguments of an internal job.
- **Critical Bug Fixes:** Fixes large NVMe over TCP transfers failing with I/O errors on connected hosts, which could silently lose data on some file systems, fixes an error that prevented saving changes to SMB service settings when directory services are enabled, and fixes a 25.10.7 regression that caused rsync tasks with quoted values in the extra options to fail.
- **Additional Fixes:** Fixes Cloud Sync tasks failing for Backblaze B2 credentials with leading or trailing spaces, raises the TrueNAS Connect request timeout from 15 to 55 seconds so certificate generation no longer fails when the certificate authority responds slowly, and fixes apps keeping an invalid NVIDIA GPU identifier after a GPU replacement.

**Pre-Update Actions:** None required when updating from 25.10.7.
